# Commits

- Conventional Commits: `type(optional scope): description`.
- Types: `feat`, `fix`, `chore`, `refactor`, `test`, `docs`.
- Description in English, imperative, lowercase, no trailing period.
- Body: 1–2 sentences, only when the *why* isn't obvious from the subject.
- **Never** add a `Co-Authored-By: Claude` footer or a "Generated with Claude Code" line.
- One commit per logical change.
- Don't commit without `npm run typecheck` and `npm test` passing.
- Don't commit or push unless asked.
